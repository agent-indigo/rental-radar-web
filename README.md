# Rental Radar Web

## Description

This is another [refactor of the PropertyPulse project](https://github.com/bradtraversy/property-pulse/tree/refactor) from [Brad Traversy](https://github.com/bradtraversy)'s [2024 Next.js from Scratch](https://learning.oreilly.com/course/next-js-from-scratch/9781836207979/) course on [O'Reilly](https://learning.oreilly.com/home/), this time using PostgreSQL, Sequelize.js, BetterAuth.js, and Redux.js Toolkit.

My previous build of this project using the default MongoDB, Mongoose.js, NextAuth.js, and the default React.js context provider can be found in this [repository](https://github.com/agent-indigo/property-pulse-web).
